GraphAgenticRAG

IN PROGRESS
Agentic RAG · Hybrid + Graph Retrieval

A production agentic RAG system combining hybrid search (Pinecone dense + BM25 sparse) with graph-based retrieval (NetworkX) and live web search (Tavily) for multi-source Q&A.

  • LangGraph agent state machine with a verifier / re-evaluation loop that checks retrieved context before response generation.
  • FastAPI backend with SSE streaming and Supabase Auth (JWT via JWKS, ES256) for secure real-time multi-user sessions.
  • Building a RAGAS evaluation layer to measure retrieval precision and recall.
